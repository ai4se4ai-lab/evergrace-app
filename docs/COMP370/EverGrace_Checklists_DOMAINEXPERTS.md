# Domain Sign-Off Checklists — EverGrace_Checklists_DOMAINEXPERTS

This is a plain-language companion to
[DOMAIN_CHECKLISTS.md](./DOMAIN_CHECKLISTS.md), written for domain experts in
**Graphic & Digital Design**, **Communication**, **Nursing**, **Business**, and
**Jujutsu Society** who don't need (or want) the code references, file paths,
and developer terminology.

**No item, order, or count is different between the two documents** — this is
the same 5 × 32 checklist, reworded. Each row below has a **Dev #** that is
the same item number in the same section of the developer version, so a
developer and a domain expert can talk about "Design item 9" and both know
exactly what's being discussed. If you want the technical detail behind any
row — the exact file, code rule, or setting it maps to — look up that number
in [DOMAIN_CHECKLISTS.md](./DOMAIN_CHECKLISTS.md).

**How to use this document.** Work through your domain's table and, per row:

- Tick **Done** if you're happy with how it stands today, or you've already
  supplied what's needed.
- Leave it unticked and use **Comments** to say what's missing, what you'd
  like changed, or when you expect to have an answer.
- The **M/O** column is the team's starting guess at whether a row is
  **Mandatory** (we can't launch without an answer) or **Optional** (nice to
  have, won't hold things up) — feel free to disagree in the Comments column.
